1 · GitHub 토큰 연결

사이트 수정은 GitHub 저장소에 직접 커밋되는 방식입니다. 최초 1회 토큰을 등록하세요. 토큰은 이 브라우저에만 저장되며 외부로 전송되지 않습니다.

발급 방법: github.com/settings/personal-access-tokens/new (subinkong-web 계정으로) → Repository access에서 storyaiworks-site만 선택 → Permissions에서 Contents : Read and write만 부여 → Generate.

2 · 유튜브 링크 관리

전체 URL을 붙여넣으면 영상 ID를 자동 추출합니다. 비워두면 해당 자리는 "Coming Soon"으로 표시됩니다. 저장하면 1~2분 후 사이트에 반영됩니다.

3 · 이미지 교체

각 이미지의 권장 해상도에 맞춰 제작한 뒤 업로드하세요. 파일 형식이 달라도 자동 변환되며, 비율이 다르면 경고 후 업로드할 수 있습니다(이 경우 사이트에서 잘려 보일 수 있음). 반영은 1~2분 소요.
