GitHub 토큰 연결

사이트 수정은 GitHub 저장소에 직접 커밋됩니다. 최초 1회만 등록하면 이 브라우저에서 계속 사용됩니다.

발급: personal-access-tokens/new (subinkong-web 계정) → Only select repositories: storyaiworks-site → Permissions → Contents: Read and write → Generate.

사이트 미러 — 아래 구조는 실제 홈페이지 순서와 동일합니다

🖼 이미지: 해당 자리를 클릭해 교체 (호버하면 권장 해상도 표시) · ▶ 영상: 보라색 입력칸에 유튜브 URL 붙여넣기 → 하단 저장바로 일괄 배포 · 반영은 커밋 후 1~2분.
